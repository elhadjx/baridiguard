# Contributing to BaridiGuard

Thank you for your interest in contributing to BaridiGuard! 🛡️🇩🇿

We welcome contributions from everyone. Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.

## 🚀 How to Contribute

1.  **Fork the Repository**: Create a personal fork of the project on GitHub.
2.  **Clone the Fork**: Clone your fork to your local machine.
    ```bash
    git clone https://github.com/elhadjx/BaridiGuard.git
    ```
3.  **Create a Branch**: Create a new branch for your changes.
    ```bash
    git checkout -b feature/your-feature-name
    ```
4.  **Install Dependencies**: Run `npm install` to install the necessary packages.
5.  **Make Changes**: Implement your changes and ensure they follow the project's style.
6.  **Test Your Changes**: Run the bot locally and verify everything works as expected.
7.  **Commit Your Changes**: Commit your changes with clear and descriptive messages.
    ```bash
    git commit -m "Add feature: your feature description"
    ```
8.  **Push to GitHub**: Push your branch to your fork.
    ```bash
    git push origin feature/your-feature-name
    ```
9.  **Submit a Pull Request**: Go to the original repository and open a pull request from your branch.

## 📝 Guidelines

-   **Code Quality**: Ensure your code is clean, readable, and well-documented.
-   **TypeScript**: Use TypeScript features and maintain type safety.
-   **Darja Localization**: If adding user-facing messages, ensure they are in Algerian Darja to keep the experience consistent.
-   **Commit Messages**: Use descriptive commit messages that explain *what* and *why*.
-   **Security**: Never commit sensitive information (tokens, keys, etc.). Use environment variables instead.

## 🐛 Reporting Bugs

If you find a bug, please open an issue on GitHub and provide:
-   A clear description of the bug.
-   Steps to reproduce the issue.
-   Your environment details (Node.js version, OS).

## 💡 Suggesting Features

We're always looking for ways to improve! If you have an idea, feel free to open an issue or start a discussion.
